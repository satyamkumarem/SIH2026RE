## 2. Problem Deconstruction

The explicit problem description provided by Egreen Quanta is extracted into atomic requirements below [PS]:

1. **[PS-REQ-A] Teleportation-Based QDS Core:** The system must implement/simulate a quantum public key distribution and digital signature workflow grounded in Bell-state entanglement ($|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$) and quantum teleportation protocols [PS].
2. **[PS-REQ-B] Non-AI/ML Constraint:** Threat detection MUST NOT rely on artificial intelligence, neural networks, or machine learning algorithms; it must remain mathematically explainable and non-heuristic [PS].
3. **[PS-REQ-C] Quantum Principles for Detection:** Detection mechanisms must strictly utilize Pauli eigenstates ($|0\rangle, |1\rangle, |+\rangle, |-\rangle, |+i\rangle, |-i\rangle$), projective measurements ($P_\psi = |\psi\rangle\langle\psi|$), and statistical analysis of measurement outcomes [PS].
4. **[PS-REQ-D] Multi-Threat Identification:** The framework must detect five primary attack classes:
   - Digital signature forgery [PS]
   - Sender/verifier impersonation [PS]
   - Replay attacks (classical Pauli correction bit reuse) [PS]
   - Quantum channel manipulation (bit-flip, phase-flip, intercept-resend, noise injection) [PS]
   - Unauthorized verification attempts [PS].
5. **[PS-REQ-E] Statistical Threshold Methods:** The solution must evaluate quantum bit error rates (QBER) and forgery probabilities ($P_{\text{forge}}$) using statistical bounds (e.g., Hoeffding bounds, SPRT) to classify valid vs. malicious signatures [PS].
6. **[PS-REQ-F] Information-Theoretic Security Preservation:** Threat detection algorithms must preserve information-theoretic security guarantees without exposing secret key states during verification [PS].
7. **[PS-REQ-G] Deterministic Acceptance & Low Complexity:** Legitimate signatures under ideal or calibrated channel conditions must yield deterministic acceptance ($QBER = 0$ in ideal channels) with low computational complexity $O(N)$ [PS].
8. **[PS-REQ-H] Comprehensive Evaluation Suite:** The software must include mathematical modeling, an attack simulation engine, security verification proofs, and a performance benchmarking dashboard [PS].

## 10. Recommended Approach & Why

**Selected Approach: Quantum-Inspired Statistical Hypothesis Testing Framework (Approach 3)** [INFERENCE].

### Justification:
1. **Compliance with PS Constraints:** The problem explicitly prohibits AI/ML techniques (`[PS-REQ-B]`). Approach 3 uses rigorous statistical mechanics, Pauli basis projections, and Sequential Probability Ratio Tests (SPRT) [PS].
2. **Mathematical Precision:** By decoupling errors into Pauli $X$ (bit-flip), $Z$ (phase-flip), and $Y$ (combined) bases through projective measurements ($P = |\psi\rangle\langle\psi|$), the system uniquely fingerprints attack classes [INFERENCE]:
   - **Forgery:** Uniform high error across $X, Y, Z$ bases ($QBER \approx 50\%$).
   - **Replay Attack:** Perfect quantum match on replayed bits, but timestamp/nonce mismatch or state collapse on fresh verifier bases.
   - **Quantum Channel Noise:** Low-grade, asymmetric errors ($\sigma_x \neq \sigma_z$) bounded by channel calibration.
   - **Unauthorized Verification:** Random guess projective failure rate ($QBER \approx 75\%$).
3. **Information-Theoretic Security Proof:** SPRT provides an explicit upper bound on eavesdropper information leakage ($I_{E} \le 2^{-\Omega(N)}$), guaranteeing unconditional security [RESEARCHED].

### Why Alternatives Were Rejected:
- **ML Approach:** Direct violation of PS mandate (`[PS-REQ-B]`).
- **Fixed Thresholding:** Unable to differentiate environmental optical fiber noise ($QBER \sim 3\%$) from active intercept-resend attacks ($QBER \ge 25\%$), leading to high false-alarm rates [INFERENCE].

### Detailed Step-by-Step Data Flow Narrative

1. **Key Setup & EPR Generation:** The Quantum Teleportation Core generates $N$ entangled Bell pairs $|\Phi^+\rangle_{AB} = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$. Alice holds qubit $A$, Bob holds qubit $B$ [KNOWN].
2. **Signature Preparation:** Alice encodes her digital signature into a sequence of Pauli eigenstates $|\psi_k\rangle \in \{|0\rangle, |1\rangle, |+\rangle, |-\rangle, |+i\rangle, |-i\rangle\}$ [PS].
3. **Quantum Teleportation & BSM:** Alice performs Bell-State Measurement on qubit $k$ and her EPR qubit $A$. This collapses the state and outputs two classical feedforward bits $(b_1, b_2) \in \{00, 01, 10, 11\}$ [KNOWN].
4. **Attack Injection Layer (Optional Simulation Step):** If activated, the Attack Simulator modifies either classical feedforward bits $(b_1, b_2)$ (replay/forgery attack) or manipulates Bob's quantum state via unitary noise operators $U_{\text{attack}}$ [INFERENCE].
5. **Pauli Correction & Projection:** Bob receives classical bits $(b_1, b_2)$ and applies Pauli correction operator $U_{\text{corr}} = \sigma_z^{b_2} \sigma_x^{b_1}$ to his EPR qubit $B$ [KNOWN]. Bob then executes projective measurements $P_\psi = |\psi_k\rangle\langle\psi_k|$ along the target Pauli bases [PS].
6. **Statistical Threat Analysis:** Measurement outcomes are streamed into the non-AI statistical engine [PS]. The engine calculates:
   - Quantum Bit Error Rate ($QBER = \frac{N_{\text{fail}}}{N_{\text{total}}}$) [KNOWN].
   - Log-Likelihood Ratio $L_N$ under SPRT for hypothesis testing [RESEARCHED].
   - Entropy metrics and confidence levels ($1 - \alpha$) [INFERENCE].
7. **Decision Rule & Visual Alert:** If $L_N \le A_{\text{threshold}}$, signature accepted [PS]. If $L_N \ge B_{\text{threshold}}$, threat alert raised with exact attack classification (Forgery, Replay, Impersonation, Channel Noise) [PS].

## 13. AI/ML Justification

### Strict Compliance Statement
**AI/ML IS NOT USED IN THIS SYSTEM.** [PS]

The problem statement explicitly forbids AI/ML algorithms (`[PS-REQ-B]`). Below is the mathematical non-AI replacement justification for each threat detection module:

```
+---------------------------------------------------------------------------------------------------+
|                                 NON-AI DETECTION MATHEMATICAL MATRIX                              |
+---------------------+---------------------------------+-------------------------------------------+
| Threat Class        | Non-AI Mathematical Technique   | Mathematical Condition / Formula          |
+---------------------+---------------------------------+-------------------------------------------+
| Signature Forgery   | Projective Measurement Analysis | QBER = 1 - <psi|rho|psi> >= 0.25           |
| Impersonation       | Random Pauli Basis Projection   | P_accept = (1/2)^N -> 0 for N >= 30       |
| Replay Attack       | Temporal Nonce + Chi-Square     | Chi^2 test on feedforward entropy (p<0.01)|
| Channel Noise       | Asymmetric Pauli Error Matrix   | e_X != e_Z (Decoupled Bit/Phase Flip)     |
| Unauthorized Access | Entanglement Statevector Check  | Trace Distance D(rho_B, I/2) == 0         |
+---------------------+---------------------------------+-------------------------------------------+
```

1. **Digital Signature Forgery Detection:**
   - *Input:* Teleported state $\rho_{\text{rec}}$, reference state $|\psi\rangle$.
   - *Method:* Projective operator $P = |\psi\rangle\langle\psi|$. Fidelity $F = \text{Tr}(\rho_{\text{rec}} |\psi\rangle\langle\psi|)$.
   - *Why No AI Needed:* Forged states prepared without knowing the secret basis yield $F \le \frac{1}{2}$ deterministically [KNOWN].
2. **Replay Attack Detection:**
   - *Input:* Classical feedforward bit sequence $(b_1, b_2)_k$ and timestamp nonce.
   - *Method:* Sliding window entropy check + sequence hash comparison.
   - *Why No AI Needed:* Replayed bits exhibit zero cross-correlation with fresh independent EPR measurements [INFERENCE].
3. **Quantum Channel Manipulation:**
   - *Input:* $N$-qubit measurement vectors in $X$ and $Z$ bases.
   - *Method:* Decoupled error rates $e_X = \frac{1}{N}\sum (1 - \langle X \rangle)$, $e_Z = \frac{1}{N}\sum (1 - \langle Z \rangle)$. Sequential Probability Ratio Test (SPRT) [RESEARCHED].
   - *Why No AI Needed:* SPRT provides optimal decision boundaries under Neyman-Pearson lemma without training models [RESEARCHED].
